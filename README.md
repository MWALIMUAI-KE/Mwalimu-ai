# Mwalimu AI — First Road-Test MVP

Upload a readable PDF question paper and generate a structured marking scheme.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Required deployment secret
`OPENAI_API_KEY`

Optional:
`OPENAI_MODEL` (defaults to `gpt-4.1-mini`)

This is the first runnable MVP, not the complete production system.
